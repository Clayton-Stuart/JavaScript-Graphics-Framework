Overview

 Back to top

The purpose of this framework is to provide a simple interface to create graphical elements composed of grids of colored pixels. There are a variety of methods to interact, write to, and read data from the grid.











init()

 Back to top

To use the framework, it must be included in an html document.

<script src="grid-graphics.js"></script>

The framework works by using a "div" element with an id, and turning that into a grid. To start, create a div element in your document and give it an id. To initialize the grid, use the init() function.

init(id, size, gridSize, forceSquare, debug)

  • "id" is the id of the grid
  • "size" is an array of two values. For example: [1000, 700] where 1000 is the width of the grid in px and 700 is the height of the grid in px
  • "gridSize" is one value. It is how many rows tall the grid will be. If gridSize = 15, the grid will be 15 rows tall, and how many columns is automatically filled so that the width of each column most closely matches the height of each r
  • "forceSquare" is set to false by default. by setting it to true, it ensures the width of each column matches exactly the height of each row. If it does not divide the grid perfectly, there will be a leftover less than the width of one column
  • "debug" is set to false by default. By setting it to true, it makes every cell on the grid a different color from its neighbor. Any excess if forceSquare is true is marked and black and grey











debugGrid()

 Back to top

This function does the exact same thing as the "debug" option in the init() function. Adds the red, blue, and green pixels back to the grid along with the black and grey background for extra space with forceSquare

debugGrid(id)

"id" is the ID of the grid











clearGrid()

 Back to top

This function removes any colors from the grid including the black and grey background for extra space with forceSquare from debug or debugGrid. Also resets all default-color attributes back to white

clearGrid(id)

"id" is the ID of the grid











grabPixel()

 Back to top

This function return a pixel in the form of a div element when called and given accurate coordinates.

grabPixel(id, x, y)

"id" is the ID of the grid
"x" and "y" are the coordinates of the pixel.











grabBlock()

 Back to top

This function return a block in the form of a 2d array of div elements when called and given a pair of accurate coordinates. This array will be used in many of the other functions.

grabBlock(id, x1, y1, x2, y2)

"id" is the ID of the grid
"x1" and "y1" are the coordinates of the start pixel of the block. Must start in the top leftmost corner of the block
"x2" and "y2" are the coordinates of the end pixel of the block. Must be the bottom rightmost corner of the block











changeBlockColor()

Change the color of the block of pixels. Takes a pixel array as returned by grabBlock() function.

pixelArray is a 2d array of pixels as returned by grabBlock()











revertBlock

 Back to top

Takes a pixel array as returned by grabBlock() function and changes the background color of each pixel the equal the value of the default-color attribute

revertBlock(pixelArray)

"pixelArray" is a 2d array returned by grabBlock()











returnGridSize()

 Back to top

Returns the size of the grid. Gives width and height of the grid in pixels. Gives the width and height of each pixel in pixels. Gives how many elements wide and tall the grid is.

returnGridSize(id)

"id" is the ID of the grid


returned values can be seperated by the following: returnGridSize(id).gridWidth :: (Gives the width of the grid in pixels) returnGridSize(id).gridHeight :: (Gives the height of the grid in pixels) returnGridSize(id).pixelWidth :: (Gives the width of the a pixel in pixels) returnGridSize(id).pixelHeight :: (Gives the height of the a pixel in pixels) returnGridSize(id).pixelAmountWidth :: (How many elements wide the grid is) returnGridSize(id).pixelAmountHeight :: (How many elements tall the grid is)











setBackgroundColor()

 Back to top

"id" is the id of the grid

setBackgroundImage()

 Back to top

Takes an array of colors as given by the Array Generator. Sets the default-color attribute of each pixel of the grid to match the image.
When creating the image with the Array Generator, use the pixel amount height and pixel amount width as returned by the returnGridSize() function.

setBackgroundImage(id, colorArray)

"id" is the id of the grid
"colorArray" is the array of colors to set the background











registerEntity()

 Back to top

Stores a array of colors that can be called and drawn on the grid using the drawEntity() function. It is a 2d array of colors that can either be written, or generated using the Array Generator

registerEntity(name, colorArray)

"name" is the name of the name of what the entity will be called
"colorArray" is the array of colors to set the color

rectanglesCollide()

 Back to top

Returns a true or false value depending on if two given rectangles overlap

rectanglesCollide(box1, box2)

box1 and box2 are arrays of rectangle coordinates. They will each contain 4 values representing the top left and bottom right corners of the two rectangles in the form of [x1, y1, x2, y2], for example:
box1 = [2, 4, 9, 12]
box2 = [5, 6, 14, 16]

In this example, the top left corner of the box1 is (2, 4) and the bottom right corner of box1 is (9, 12)
And for box2, the top left corner is (5, 6) and the bottom right corner is (14, 16)

Using the Array Generator

 Back to top

This is a HTML page that allows you to draw on a canvas and export it to an array that can then be used in the grid. To start, press the "start new grid" button and input a height and width. To change colors, click the different colored circles at the top of the page. By default each cell is filled with transparency. There isn't a way to see the difference between white and transparency. To fill with white, use the empty circle with the word "white" inside it. The fill with transparency, use the empty circle with the word "clear". To choose a color not available from the circles, use the circle labeled "CC" and input a color using hexadecimal notation (needs to have the "#" in front still). To export the grid, use the "export" button and copy into a program to use it.











default-color Attribute

 Back to top

default-color is an attribute that every pixel on the grid has. When the revertBlock() function is called, any affected pixels will have their color returned to the value of this attribute.
